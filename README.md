# Shimpz SDK

Language SDKs for authoring and running Shimpz Assistants.

The repository is organized by public language surface. Shared deterministic
behavior lives in `shimpz-genesis`, a Rust foundation consumed by bindings and
the Shimpz CLI.

## Roadmap

1. `crates/shimpz-genesis` — shared Rust foundation.
2. `python` — Python package `shimpz`.
3. `typescript` — future TypeScript SDK.
4. `rust` — future public Rust crate `shimpz`.

Only active implementations have directories. Placeholder SDKs are not
shipped.
